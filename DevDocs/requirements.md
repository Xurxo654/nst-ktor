# Studios
- [x] Application needs a studio data type
- [x] Studio data type should have a name, a unique shortcode
- [x] Application needs a post endpoint to create studio
- [x] post endpoint should not allow creation of duplicate studio codes
- [x] Application needs a get endpoint to retrieve all studios
- [x] Application needs a get endpoint to retrieve a single studio
# Scene
- [x] Application needs a data type for representing Scenes
- [x] Scene datatype should have a title
- [x] Scene datatype should have a description
- [x] Scene datatype should have a studio
- [x] Scene datatype should have a rating
- [x] Scene datatype should have a release date as a string following ISO 8601 partial strings (2019, 2019-03, 2019-03-14)
- [x] Scene datatype should have a unique ID
- [x] Application needs a get endpoint to retrieve a single scene by ID
- [x] Application needs a get endpoint to retrieve all scenes
- [x] Application needs a post endpoint to create a scene
  - [x] at a minimum the post method requires a title and a studio
  - [x] the post endpoint can also accept release date, description, rating
  - [x] A scene from a studio cannot have the same title as another scene from the same studio
